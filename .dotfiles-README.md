# Dotfiles

Managed with a **bare git repo** at `~/.dotfiles` (no symlinks needed).

## Usage

Add this alias to your shell rc (`.zshrc` / `.bashrc`):

```sh
alias dot='git --git-dir=$HOME/.dotfiles --work-tree=$HOME'
```

Then manage files like normal git:

```sh
dot status
dot add .zshrc
dot commit -m "tweak zsh"
dot push
```

`status.showUntrackedFiles` is set to `no`, so `dot status` only shows files
you've explicitly added. A safety exclude list lives in
`~/.dotfiles/info/exclude` to keep secrets/state out even on `dot add -A`.

## Cloning on a new machine

```sh
git clone --bare <repo-url> $HOME/.dotfiles
alias dot='git --git-dir=$HOME/.dotfiles --work-tree=$HOME'
dot checkout            # resolve conflicts with pre-existing files if any
dot config status.showUntrackedFiles no
```

## What is tracked

Shell, editor, X11/i3, and selected `~/.config` app configs. Secrets
(`.ssh`, `.gnupg`, `.password-store`, plaintext-credential files like
`.mpdasrc`) and machine state (caches, histories, app data) are deliberately
excluded.
